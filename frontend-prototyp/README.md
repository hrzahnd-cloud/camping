# Frontend-Prototyp (Lookalike)

`CampingVerwaltungLookalike.jsx` ist ein rein visueller, NICHT
funktionaler Prototyp der Benutzeroberfläche (statische Demo-Daten,
keine echten API-Aufrufe). Gedacht als gemeinsame Diskussionsgrundlage
für das spätere echte Frontend, nicht als Ausgangscode dafür.

Abhängigkeiten (Peer, nicht im Backend-requirements.txt enthalten):
react, lucide-react, recharts. Tailwind-Core-Utility-Klassen werden
verwendet (kein JIT-Compiler nötig, aber ein Tailwind-Setup muss
vorhanden sein, damit die Klassen greifen).
